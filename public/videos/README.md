# Ambient television video

`cofounder-2-hero.mp4` was supplied by Rajdeep for this portfolio, following the [Cofounder landing-page reference](https://cofounder.co/). The original file is stored unchanged: H.264, 1920 × 1122, 24 fps, 2.375 seconds, 209,752 bytes, no audio track. This is a third-party reference asset, not original portfolio artwork.

`cofounder-2-hero.webp` is a 960-pixel-wide first-frame poster extracted from that file. The TV applies the same 4:3 cover crop to both sources at render time.

# Cursor cat

`oneko.gif` is the unchanged 256×128 classic cat sprite sheet from
[adryd325/oneko.js](https://github.com/adryd325/oneko.js/blob/main/oneko.gif), retrieved September 26, 2026.

SHA-256: `f4c5688eb8ee6f22b08ab8df361222307dc6fe2d5bdcfa12582cea694707e66d`.

The upstream project distributes this with the included MIT [LICENSE.txt](LICENSE.txt), copyright © 2022 adryd. The classic Neko artwork traces back to the original Neko/Oneko cursor pets. Our React component adapts the upstream sprite mapping, movement and idle behaviors with lifecycle cleanup, responsive/reduced-motion handling and Doom integration. No third-party script executes at runtime.

[ramx.in](https://ramx.in/) is the interaction reference; its current custom avatar sprite is not included. This portfolio uses the classic cat requested by Rajdeep.

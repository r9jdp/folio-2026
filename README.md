# Rajdeep Pandey — minimal portfolio

A fresh white portfolio with an original 3D retro monitor and straightforward text about my work. Built on `feat/minimal-monitor-pond`; the Porsche version is preserved on `main` at `17f1f6f`.

## Run locally

```sh
npm ci
npm run dev -- --port 3013
```

This first milestone contains the page, résumé-based writing, and original procedural monitor, keyboard, and mouse. The interactive pond is the next milestone.

The references are [Henry Heffernan](https://henryheffernan.com/), [Shawn](https://www.shwn.design/), and [Adi Singh](https://www.adisingh.com/). No models or artwork are copied from those sites.
